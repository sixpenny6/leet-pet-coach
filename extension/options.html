01 / 选择你的模型服务

可填写基础地址，自动补全 /chat/completions 或 /messages。自建网关也可以填写完整接口地址。

密钥保存在此浏览器扩展本地存储，不会同步到云端。请求由扩展后台直接发往你填写的服务地址。设置文件不包含预置密钥。

02 / 调整回答方式

内置要求：中文、零基础、逐步提示、不假装运行代码。具体教学模式在鲸鱼娘对话窗里切换。

配置好，就能开始。

  1. 填写接口地址、模型 ID 和密钥。
  2. 点击保存，允许访问这个 API 域名。
  3. 回到力扣并刷新，点击右下角鲸鱼娘。
  4. 读取代码，再问一个具体问题。
