刷题搭子 v1.2.0

1. Chrome 打开 chrome://extensions（Edge 用 edge://extensions）。
2. 打开“开发者模式”→“加载已解压的扩展程序”。
3. 选择本文件所在目录，目录中应包含 manifest.json。
4. 刷新力扣题目页，点击右下角鲸鱼娘，再点齿轮配置模型。
5. 填写模型 ID、API 地址与自己的 Key，保存并授权 API 域名。
6. 先点击读取，核对代码附件，再发送问题。

支持 leetcode.cn 与 leetcode.com。代码运行和提交仍然由力扣完成。
不用 npm install，不用额外后端。此安装包不包含任何密钥。
它不会继承你现有的 AI 聊天历史；API 调用使用你配置的服务商账户。
配置后请先测试连接。API Key 保存在当前浏览器扩展本地存储（未加密、不云同步）。

v1.0.1 新增：设置页顶部“从 sandbox.txt 导入 DeepSeek”。
选择原配置文本文件后，只提取明确标注 DeepSeek 的密钥，忽略其他供应商。
模型自动设为 deepseek-flash（当前由 Flash 1017 提供服务）。
导入后点击“保存并授权接口”，然后测试连接。
